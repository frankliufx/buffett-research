# 二、巴菲特指标（市场估值核心标准）

## 1. 指标定义

巴菲特指标（又称**证券化率**），是股神巴菲特用来判断**全球/一国股市整体估值高低**、衡量市场泡沫程度的核心指标，被誉为“判断股市整体水位的万能标尺”。

## 2. 计算公式

 $\text{巴菲特指标} = \frac{\text{股市总市值（全部上市公司市值之和）}}{\text{国内生产总值（GDP）}} \times 100\%$ 

简单理解：股市总市值 ÷ 国家GDP × 100%，比值反映股市相对实体经济的估值水平。

## 3. 估值判断标准（通用参考）

|指标比值|市场估值判断|投资建议|
|---|---|---|
|＜70%|严重低估（市场处于底部区域）|适合分批布局、加仓|
|70%~90%|合理偏低（估值温和，安全边际高）|坚定持有，适度建仓|
|90%~120%|合理区间（估值中性，市场平稳）|均衡配置，观望为主|
|120%~150%|偏高估值（存在泡沫风险）|减仓避险，控制仓位|
|＞150%|严重高估（泡沫极大，风险极高）|清仓离场，规避大跌风险|
## 4. 实操注意事项

- 数据口径：选用**年度GDP**、对应时段股市总市值，数据需权威（国家统计局、交易所官网）

- 适用场景：侧重判断**大盘整体趋势**，不针对个股选股；成熟市场参考性更强

- 灵活调整：结合市场利率、政策环境微调阈值，不可单一照搬比值
